# Product and architecture review — 2026-09-05

## Verdict

This working tree is a functional release candidate for local guided diff review. Keep the existing pure guide engine, Git protocol, Reatom model and editor adapters; a rewrite would discard meaningful safety coverage without solving the missing user flow. The release candidate remains version 0.0.0. Public distribution and broader host qualification are still release tasks, not evidence supplied by a passing unit suite.

The workspace already contained substantial apply-mode and recovery work. This pass preserved it and repaired the user-facing flow around it; the total working-tree diff must not be attributed solely to this review.

## Findings addressed

| Priority | Finding | Resolution |
|---|---|---|
| P1 | No persistent explanation while navigating | Activity-bar Walkthrough view with summary, current rationale, full plaintext notes, progress and controls; final notes remain visible |
| P1 | Saving after planning could invalidate the stash decision | Save repository buffers before planning; re-probe and compare the plan after confirmation |
| P1 | Concurrent preparation, navigation, Finish or recovery could race | Reserve lifecycle state before awaited work; cancellation drains isolation; stale modal answers are ignored |
| P1 | A journal write failure could strand the repository lock | Release the acquired lock if the first durable token write fails |
| P1 | Unsafe apply targets could be partially reproduced | Refuse binary, structural, symlink, submodule and unsupported stub targets with restoration |
| P1 | Save/open operations could select the wrong repository path | Canonical repository containment and explicit root at the port boundary |
| P1 | Journal context could disappear during shutdown | Capture the storage context; missing storage fails instead of pretending to persist |
| P2 | Final-newline changes rendered incorrectly | Track markers by patch side and use the post-image marker on completion |
| P2 | Obsolete editor opens or decorations could affect another step | Generation checks, exact URI matching and cleanup of review tabs |
| P2 | Go to current change left focus in the sidebar | Activate the diff even when already visible |
| P1 | Native apply waited for a toast dismissal | Notices without action buttons return immediately; confirmations still await a choice |
| P1 | Apply Cancel collided with re-created untracked files | Remove only paths recoverable from the original stash before restoring it |
| P2 | Checkpointed additions looked like unrelated drift | Compare full working trees, including untracked content |
| P2 | Command failures were silent | Report actionable errors; expected aborts remain quiet |
| P2 | Packaging workflow used a nonexistent script | Use ext:package; lint, typecheck and tests precede packaging and release creation |

## Scope decisions

The initial public promise is local, offline guided review in an explanation-first order. Remote PR ingestion, account features and automatic LLM guide generation are outside this release candidate. Apply remains deliberately narrower than read-only. Notes are displayed as safe plaintext with line breaks, not interpreted Markdown. Multi-root workspaces use the first folder. These constraints are stated in the README rather than hidden behind optimistic marketing.
